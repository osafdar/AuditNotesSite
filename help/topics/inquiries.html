Inquiries

Inquiries (often referred to as Checklists or Assessments, depending on the nature of the audit) are structured questions or checks used by auditors to design a standardized audit across multiple auditees.

They ensure that all critical areas pertaining to the selected Schema Items are comprehensively covered. During an audit, you can use these inquiries to smoothly record responses directly from the auditee.

Recording Inquiry Responses

For the selected Item, if inquiries have been defined, the auditor can enter responses by clicking the Item Notes/Assessments tab. This provides a structured view where each inquiry can be reviewed and answered directly during the audit.

Important: Inquiry responses can only be recorded against items that are linked with the audit. If an item is unlinked from the audit after responses have been recorded, the auditor's responses will be permanently deleted.

Linking with Schemas

Inquiries are tightly integrated with your audit structure to maintain logical organization:

  • Schema: Inquiries are housed under a specific overarching Schema.
  • Schema Item Category: They are organized under relevant categories (e.g., Clauses or Controls).
  • Schema Item: Each Inquiry is linked directly to a specific Schema Item to ensure targeted assessment.

Managing Inquiries

You can easily shape your checklist using the tools provided on the Inquiries pane:

  • Add Related Item: Allows you to associate an inquiry with additional Schema Items if a single check applies to multiple areas.
  • Remove Related Item: Unlinks an inquiry from a Schema Item without deleting the inquiry itself.

Data Management and Bulk Entry

Just like Schemas, all Inquiry data is securely saved in an Excel file. This enables rapid bulk data entry.

To perform bulk updates:
  1. Navigate to the Inquiries tab located on the right pane.
  2. Click on Open Data File to view the underlying Excel file.
  3. You can now efficiently add or update multiple inquiries directly within the spreadsheet.
Important: The file will have the same name as the Schema File Name.
