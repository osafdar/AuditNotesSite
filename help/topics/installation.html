Installation

truAudits is available exclusively through the Microsoft Store, ensuring a secure and streamlined installation experience.

Why the Microsoft Store?

Installing truAudits from the Microsoft Store offers several important security advantages:

  • Every app published on the Microsoft Store is reviewed and digitally signed by Microsoft, ensuring it has not been tampered with.
  • Apps are distributed in secure packages that run in a sandboxed environment, reducing the risk of malware or unauthorized system changes.
  • Updates are delivered automatically through the Store, so you always have the latest security patches and features without manual intervention.
  • You avoid the risks associated with downloading installers from unknown or third-party websites.

System Requirements

truAudits requires Windows 10 version 14393.0 or higher. Please ensure your operating system meets this minimum requirement before proceeding with the installation.

How to Install truAudits

Follow these steps to download and install truAudits from the Microsoft Store:

  1. Open the Microsoft Store on your Windows device. You can find it by clicking the Start button and selecting Microsoft Store from the app list, or by searching for Microsoft Store in the Start menu search bar.
  2. In the Microsoft Store, click on the Search bar at the top of the window.
  3. Type truAudits in the search area and press Enter.
  4. Locate truAudits in the search results and click on it to open the app listing.
  5. Click the Get or Install button to begin the download and installation.
  6. Wait for the installation to complete. The Microsoft Store will notify you once the app is ready to use.

Launching truAudits

Once installed, you can open truAudits by clicking the Start button and looking for truAudits in the app list. You can also type truAudits in the Start menu search bar for quick access.

Local Data Storage

truAudits stores all data on your local machine within your specified Document Repository. The application creates and updates files in this directory as you work with your audits.

Important: Please ensure that you have the necessary read and write permissions on your local machine to allow truAudits to save your audit-related information. If the application does not have sufficient permissions to access the repository folder, it will not be able to store or update your data.
